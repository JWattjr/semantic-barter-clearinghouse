# Mechanism differentiation

## Nearest comparison

The closest local comparison is ClaimNet Semantic Exposure Graph, which classifies semantic relationships among claims. This project uses semantic judgment to decide a directed compatibility edge between a specific giver's offer and a specific receiver's request, then requires all owners to consent to the exact ordered cycle.

## Distinct interaction and invariant

The exchange is a bounded graph cycle, not a stored claim relation. A two-party cycle requires both directed edges; a three-party cycle requires all three edges. Each edge names concrete offer keys from the same snapshot. Participants separately approve the resulting cycle. Execution moves the exact asset IDs and units already reserved by those offers and consumes each offer once. Per asset, `available + reserved == faucet-minted` before and after each transition.

The distinctive demonstration is a three-party cycle where every participant accepts the next participant's item, while the candidate two-party cycle fails on its missing reverse compatibility edge.

## Limits of the comparison

Descriptions and model assessments do not establish ownership, quality, title, delivery, or global semantic truth. Assets are synthetic ledger balances. This local comparison does not claim ecosystem-wide originality or Portal outcomes.
